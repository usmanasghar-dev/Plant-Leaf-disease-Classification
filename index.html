01 / PROJECT OVERVIEW

Making leaf analysis more accessible.

This project explores how deep learning can classify tomato leaf images and distinguish selected healthy and diseased leaves.

⌕

Image-based analysis

Leaf images are used as input to an image-classification model.

◈

Three categories

Early Blight, Late Blight, and Healthy tomato leaves.

⌁

Custom CNN

A convolutional neural network trained with TensorFlow and Keras.

02 / MODEL DETAILS

A custom CNN built for classification.

The model processes a resized RGB image and produces class scores across three selected categories.

01 · Input image 128 × 128 × 3 · RGB · normalized to 0–1

02 · Convolution + pooling Feature extraction with 32, 64 and 128 filters

03 · Dense + dropout 128-unit dense layer with dropout

04 · Softmax output 3 class probabilities
