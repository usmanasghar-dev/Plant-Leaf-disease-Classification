
# 🌿 Plant Leaf Disease Classification Using CNN

## 📌 Project Overview
This project uses a Custom Convolutional Neural Network (CNN) to classify plant leaf diseases from images using deep learning.

## 🎯 Objectives
- Detect plant leaf diseases.
- Classify healthy and diseased leaves.
- Apply deep learning for image classification.

## 🛠️ Technologies Used
- Python
- TensorFlow / Keras
- Convolutional Neural Network (CNN)
- NumPy
- Matplotlib
- Google Colab

## 📂 Project Files
- `plant_leaf_disease_cnn.py` - CNN model implementation.
- `requirements.txt` - Required Python libraries.
