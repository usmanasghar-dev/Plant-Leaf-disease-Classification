
# 🌿 Plant Leaf Disease Classification Using CNN

## 📌 Project Overview
This project uses a Custom Convolutional Neural Network (CNN) to classify plant leaf diseases from images using deep learning.

## 🎯 Objectives
- Detect plant leaf diseases.
- Classify healthy and diseased leaves.
- Apply deep learning for image classification.

## 🛠️ Technologies Used
- Python
- TensorFlow / Keras
- Convolutional Neural Network (CNN)
- NumPy
- Matplotlib
- Google Colab

## 📂 Project Files
- `plant_leaf_disease_cnn.py` - CNN model implementation.
- `requirements.txt` - Required Python libraries.

## 🧠 Model Information
A custom CNN model is trained to classify plant leaf images.

## 📦 Trained Model Weights
[Download Plant Disease Model ZIP](https://drive.google.com/file/d/1PVYSQ2ebVoYGqb26Aic1-birk9JD50gI/view?usp=drivesdk)

## 🚀 How to Run

1. Clone this repository.
2. Install the required libraries:

```bash
pip install -r requirements.txt
```

3. Run the Python file:

```bash
python plant_leaf_disease_cnn.py
```
