# 🌿 Plant Leaf Disease Classification Using CNN

## 📌 Project Overview

This project uses a Custom Convolutional Neural Network (CNN) to classify tomato leaf diseases from images using deep learning.

## 🎯 Objectives

* Detect plant leaf diseases.
* Classify healthy and diseased leaves.
* Apply deep learning techniques for image classification.

## 🛠️ Technologies Used

* Python
* TensorFlow / Keras
* Convolutional Neural Network (CNN)
* NumPy
* Matplotlib
* Google Colab

## 📂 Project Files

* `plant_leaf_disease_cnn.py` - CNN model implementation.
* `requirements.txt` - Required Python libraries.

## 🧠 Model Information

* Architecture: Custom CNN
* Framework: TensorFlow / Keras
* Input Image Size: 128 × 128 × 3
* Number of Classes: 3

## 🚀 How to Run

1. Clone this repository:

```bash
git clone https://github.com/usmanasghar-dev/Plant-Leaf-disease-Classification.git
```

2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Run the Python file:

```bash
python plant_leaf_disease_cnn.py
```
